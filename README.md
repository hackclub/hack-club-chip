# Hack Club Chip

This is Hack Club's very own multi-project chip, entirely designed by teenagers!

How it works is we split the core area of the chip into over 100 individual tiles which each represent a distinct chip design you make. We'll multiplex all these tiles onto the pins of the chip, so you can toggle and view any of the designs individually, including yours!

The chip is part of wafer.space Global Foundries run 3 and is built off of the Tiny Tapeout workflows so it's really easy to get your chip design onto the shared chip!

With the help of DeepAI, we're manufacturing this chip on December 16th and will fully sponsor any teenagers design onto the chip; just go to https://asic.hackclub.com to get started!

## Extra Info

- Visit https://tinytapeout.com or https://asic.hackclub.com for more information on the project.

To learn about the chip's architecture, please refer to [the multiplexer documentation](https://github.com/TinyTapeout/tt-multiplexer/blob/main/docs/INFO.md).

If you want to build this design yourself, please refer to [BUILDING.md](BUILDING.md).
